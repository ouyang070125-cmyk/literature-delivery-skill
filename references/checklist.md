# Delivery checklist

## Before opening a browser

- [ ] The user has given a title, DOI, or unambiguous citation.
- [ ] The exact item type is known: article, conference paper, book/chapter, standard, or supplement.
- [ ] The recipient email is confirmed.
- [ ] The user knows which service will be used and whether it may consume quota/fee.
- [ ] Lawful OA has already been checked and rejected or accepted.

## Before submitting

- [ ] The delivery modal's title matches the requested title, not just the search result.
- [ ] Author/year/DOI or paper number matches.
- [ ] The email is spelled correctly.
- [ ] This is not a duplicate of an existing request.
- [ ] If the missing item is a supplement, the main article is **not** being re-requested without consent.

## After submitting

- [ ] Success text appeared; the click alone is not evidence.
- [ ] Order number captured verbatim.
- [ ] ETA captured verbatim.
- [ ] Receipt saved without cookies/passwords.
- [ ] Follow-up date set.
- [ ] User told what happens next and what to check (spam folder, ETA).

## When the PDF arrives

- [ ] File opens and is a real PDF.
- [ ] Title/author/page range match.
- [ ] Text is selectable (not a screenshot of one page).
- [ ] Supplement/main-text distinction is clear.
- [ ] Receipt status changed to `received`.
